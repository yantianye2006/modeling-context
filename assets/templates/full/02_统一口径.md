## 图表口径

适用范围：所有进入交付物的成稿图。探索图和调试图不受本节约束，也不得据此进入交付物。
填写时机：确定交付排版模板后、进入论文交接模式前。本节是下游绘图阶段的强制输入，用于覆盖绘图工具自带的默认风格。
需求侧的逐张图定义见 [[交付物清单]] 中 `kind: figure` 的条目，本节只规定全项目统一的呈现口径。

### 分类判据：违反能否在成品图上被看见

口径项分三类填写，**判据是"违反了能不能在成品图上一眼看出来"**，不是"能不能写成断言"：

| 类别 | 判据 | 处理方式 | 典型项 |
| --- | --- | --- | --- |
| A 硬断言 | 违反在成品图上**看不见**：再认真的目视检查也发现不了 | 必须写成出图脚本内的断言，不符即中止出图 | 输出格式与字体嵌入、产物目录同步、跨图色板一致、画布尺寸、页面预算、产物文件真实字号、文字重叠与出血 |
| B 验收目标 | 违反在成品图上**看得见**：读者一眼就会发现 | **不设数值门禁**，只写目标；由 C 类回看确认 | 可读性、排版密度、图例是否遮数据、面板是否自解释、热图是否可量化 |
| C 强制观察 | —— | 出图后必须把产物渲染回看，并与上一版并排对比 | 见本节末 |

把 B 类写成数值门禁是本节最常见的失效方式，机制如下：数值门禁一旦通过，就**没有人再去看那张图**——它把"检查"这个动作从真做变成了跑一遍断言。而门禁的分辨率恒定，模型和人的判断力不是；能力越强，被固定数值卡住的损失越大。**A 类断言全部通过不等于图可用**，这句话必须写进出图脚本的输出。

已观测到的后果（全部肉眼可见，也全部通过了当时的机械校验）：单图连题注占满整页；多处文字互相压字；产物中出现低于自身下限的字号——数学上下标被自动缩小，查绘图对象查不出；口径要求的线型区分从未被实现。这四项正是「A 类断言 + 无人回看」的典型产物，因此 C 类回看不是补充检查，而是与 A 类并列的必需环节。

A 类每一项都必须填写「校验函数」：**只写在本节、没有任何一环执行的口径，等同于未声明**。可靠性排序：出图脚本内的断言 → 独立校验脚本 → 人工逐张核对；只能人工核对的项，在论文前门禁中逐项过一遍。

### A 类：硬断言

| 口径项 | 取值 | 取值来源与约束 | 校验函数 |
| --- | --- | --- | --- |
| 画布宽度 |  | 排版模板正文宽度实测值；按此宽度出图并 1:1 引用，不在排版阶段缩放 |  |
| 画布高度上限 |  | 按"单图 + 题注不超过页面文字区的 2/3"反推的毫米值。**缺了这一项，字号下限会把画布不断顶高**：字号绝对、宽度锁死时，唯一的自由度就是拉高画布，结果是单图占满整页 |  |
| 产物文件最小字号 |  | 校验对象必须是**产出的 PDF/PNG 文件**，不是绘图库的内存对象。数学上下标会被自动缩到约 0.7 倍，声明 8 pt 的文本在产物里可能只有 5.6 pt，查内存对象一定漏。取值参考期刊惯例（5–7 pt），不要照搬"正文字号的 2/3"这类海报口径 |  |
| 文字重叠与出血 |  | 渲染后逐对求交：任意两处文字包围盒交叠不得超过较小者的约定比例；所有文字必须落在画布内。这是最容易被遗漏、却最影响观感的一项 |  |
| 图内总标题 |  | 只禁**图级总标题**（与题注机制二选一）。不要连面板级小标题一起禁掉——小标题不与题注重复，且是 B 类"自解释"的主要手段 |  |
| 图内语言与字体 |  | 与交付物正文一致 |  |
| 面板编号 |  | 多面板图的编号形式与位置；全项目统一 |  |
| 量纲呈现 |  | 与正文数值口径一致；不一致时必须在图注标注换算关系 |  |
| 色板与第二重区分 |  | 项目级复用；同一变量跨图同色；需通过色觉障碍可辨性检查；同时登记线型/标记作为颜色之外的第二重区分。**"要求了第二重区分"与"实现了第二重区分"是两件事，必须有断言检查登记表与变量表一致** |  |
| 输出格式 |  | 引用格式（矢量、字体嵌入）与预览格式分别声明 |  |
| 单章成稿图上限 |  | 按交付物篇幅与赛制约束确定；供论文前门禁校验，超出需书面说明 |  |

### B 类：验收目标（不设数值门禁）

| 目标 | 含义 |
| --- | --- |
| 可读性 | 按交付尺寸打印、与正文并排时，图内最小文字可辨认。A 类的字号下限是**产物下限不是设计目标**，禁止为满足某个字号而拉高画布 |
| 页面预算 | 图 + 题注不挤占该页的正文空间 |
| 自解释 | 每面板一行小标题（含量纲），图底一行数据范围与标准化脚注；读者不看题注也知道面板在画什么 |
| 图例不遮数据 | 图例置于绘图区之外或确证的空白区；多面板共用同一图例时只画一次 |
| 可量化 | 热图等以颜色编码的图逐格标注数值，不让读者只凭颜色估计量级 |

B 类**不写例外条款**。遇到"这张图放不下数值/放不下标签"时，正确动作是腾空间（去掉冗余的颜色条、改标整数倍数、重排面板宽度），不是给这张图免检——给自己的规则开口头后门，与用错误的数值门禁是同一种失败。

### C 类：强制观察

出图脚本执行完毕后，**必须把产出图渲染回看一遍，并与上一版并排对比**，逐项确认 B 类目标，结论记入 [[交付物清单]] 对应 `figure` 条目的 `产物回看` 字段。只有回看改变了采用方案、条目状态或既有决策时，才追加到 [[决策日志]]。任何“断言通过即交付”的流程视为未完成出图。

### 产物目录与同步

成稿图若同时存在于出图目录与交付物目录，必须声明哪一份是权威源以及同步方式。
同步应由出图脚本在同一次保存中完成：手工拷贝会产生两份可以各自更新的副本，而没有任何环节会发现它们已经不一致。

## 参考文献口径

著录格式统一采用 **GB/T 7714-2015《信息与文献 参考文献著录规则》**，顺序编码制。文献登记见 [[文献库/README]]，本节只规定著录形式。

| 口径项 | 约定 |
| --- | --- |
| 标注体系 | 顺序编码制，按正文首次出现顺序连续编号 |
| 作者著录 | 姓在前名在后；不超过 3 位全部著录，超过 3 位著录前 3 位后加“等”（西文加“et al.”） |
| 文献类型标识 | 必须著录：专著 [M]、期刊 [J]、学位论文 [D]、报告 [R]、标准 [S]、专利 [P]、论文集析出 [C]、报纸 [N] |
| 电子资源 | 附载体标识与获取路径，如 [J/OL]、[EB/OL]、[DB/OL]，含引用日期与 URL 或 DOI |
| 页码 | 期刊著录起止页码；专著著录引文页码 |

常用类型著录格式：

```text
期刊    主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
专著    主要责任者. 题名[M]. 版本项. 出版地: 出版者, 出版年: 引文页码.
析出    析出文献主要责任者. 析出题名[C]//论文集主要责任者. 论文集题名. 出版地: 出版者, 出版年: 起止页码.
学位论文 主要责任者. 题名[D]. 保存地: 保存单位, 年份.
标准    标准编号 标准名称[S]. 出版地: 出版者, 出版年.
电子    主要责任者. 题名[EB/OL]. (更新日期)[引用日期]. 获取路径.
```

排版实现（BibTeX 样式、引用命令、编号形式）属于交付阶段事项，但不得改变上述著录口径。
